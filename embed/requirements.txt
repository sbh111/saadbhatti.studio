# CPU-only Torch (no CUDA), enforced by version, not just by index. torch is
# pinned to its own "+cpu" LOCAL version — a version string PyPI's default
# index never publishes (PyPI's plain "2.13.0" is the CUDA build, pulling in
# ~1.5 GB of nvidia-* wheels). Because pip requires an EXACT match on the local
# version segment, "torch==2.13.0+cpu" can only ever be satisfied by the
# PyTorch CPU wheel index below — so --extra-index-url (which ADDS an index
# rather than replacing PyPI) stays safe here, unlike the old floor-pinned
# ">=2.2" which let pip pick either build. (The other robust option — installing
# torch by itself in its own Dockerfile RUN with --index-url — works too; this
# repo keeps one requirements file/one `pip install` instead.)
--extra-index-url https://download.pytorch.org/whl/cpu
